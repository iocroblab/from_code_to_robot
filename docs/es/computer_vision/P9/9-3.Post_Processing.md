# Postprocesamiento

En modelos de detección de objetos como YOLO, el **postprocesamiento** es esencial para refinar las predicciones en bruto realizadas por la red. Como vimos en la Lección 2, estos modelos tienden a producir un gran número de predicciones.


Este comportamiento se debe a la arquitectura del modelo, donde:

-  Cada celda de la rejilla predice múltiples anchor boxes. 
-  Las celdas vecinas pueden detectar el mismo objeto. 

Como resultado, **varias cajas solapadas pueden representar el mismo objeto**. Si conservamos todas las cajas predichas, la salida contendría muchos duplicados.


Para solucionar esto, el postprocesamiento incluye:

-  **Umbralización por confianza**: Filtra las detecciones con baja confianza. 
-  **Non-Maximum Suppression (NMS)**: Elimina cajas solapadas redundantes, conservando solo la de mayor confianza. 

Este paso garantiza resultados más limpios y precisos.


El objetivo de esta lección es aprender a implementar filtros de postprocesamiento y entender cómo pueden ayudarnos a mejorar nuestros resultados.

```matlab
function filteredDetections  = filterByConfidence(detections, threshold)
    % Elimina detecciones con confianza por debajo de un umbral.
    % Inputs:
    %   detections - Array de structs, cada uno representando un resultado de detección con campos:
    %                .boxes (Nx4): bounding boxes [x1 y1 x2 y2]
    %                .conf  (Nx1): puntuaciones de confianza
    %                .cls   (Nx1): etiquetas de clase
    %   threshold  - Valor escalar que especifica la puntuación mínima de confianza necesaria para conservar una detección
    %
    % Output:
    %   filteredDetections - Array de structs con las detecciones de baja confianza eliminadas.
    
    n = numel(detections);
    filteredDetections = [];
    for i = 1:n
        detection = detections(i);
        conf = detection.conf;
        keep = conf >= threshold;
        if keep
           filteredDetections = [filteredDetections, detection];
        else
            fprintf('Filtered: removed low-confidence detection\n');
        end
    end
end 
```


En el siguiente código, definimos una función anónima para el filtro que implementamos en el ejercicio anterior, que después usamos para crear un componente de postprocesamiento.

# Ejercicio 2 - Filtro de confianza por clases

Como en el ejercicio anterior, debes implementar un filtro de confianza que elimine detecciones con una puntuación de confianza inferior a un umbral. Sin embargo, esta vez, cada clase debe tener su propio umbral personalizado.

```
function filteredDetection = filterByClassConfidence(detection, thresholds)
   % Filtra detecciones usando un umbral de confianza específico para cada clase.
    % Inputs:
    %   detections  - Array de structs, cada uno representando resultados de detección con campos:
    %                 .boxes (Nx4): bounding boxes
    %                 .conf  (Nx1): puntuaciones de confianza
    %                 .cls   (Nx1): etiquetas de clase (como enteros empezando en 1)
    %
    %   thresholds  - Vector de umbrales de confianza específicos por clase.
    %                 thresholds(i) es la confianza mínima requerida para la clase i.
    %
    % Output:
    %   filteredDetections - Array de structs con las detecciones de baja confianza eliminadas,
    %                        donde el filtrado se aplica por clase usando los umbrales correspondientes.

end 
```

```matlab
function filteredDetections = filterByClassConfidence(detections, thresholds)
    % Filtra detecciones usando un umbral de confianza específico para cada clase.
    % Inputs:
    %   detections  - Array de structs, cada uno representando resultados de detección con campos:
    %                 .boxes (Nx4): bounding boxes
    %                 .conf  (Nx1): puntuaciones de confianza
    %                 .cls   (Nx1): etiquetas de clase (como enteros empezando en 1)
    %
    %   thresholds  - Vector de umbrales de confianza específicos por clase.
    %                 thresholds(i) es la confianza mínima requerida para la clase i.
    %
    % Output:
    %   filteredDetections - Array de structs con las detecciones de baja confianza eliminadas,
    %                        donde el filtrado se aplica por clase usando los umbrales correspondientes.

    n = numel(detections);
    filteredDetections = [];  % preasignar array de structs
    for i = 1:n
        detection = detections(i);

        cls = detection.cls;
        conf = detection.conf;
        keep = conf >= thresholds(cls);
           
        if keep
            filteredDetections = [filteredDetections, detection];
        else
            fprintf('Filtered: removed low-confidence detections (per class)\n');
        end
    end
end 
```

# Intersection over Union (IoU) 

En detección de objetos, un concepto fundamental es **Intersection over Union (IoU)**. Esta métrica cuantifica el solapamiento entre dos bounding boxes: la **caja predicha** por el modelo y la **caja ground truth**. IoU se usa para evaluar qué tan precisa es una predicción en relación con la anotación real.


Formalmente, IoU se define como la razón entre el área de intersección y el área de unión de las dos cajas:


![image_0.png](9-3.Experimentation_media/image_0.png)


El valor de IoU está acotado entre 0 y 1:

-  **IoU = 0** significa que no hay solapamiento. 
-  **IoU = 1** indica una coincidencia perfecta entre la predicción y el ground truth.

```matlab
function iou = calculateIoU(b1, b2)
    % Calcula la Intersection over Union (IoU) entre dos bounding boxes.
    %
    % Inputs:
    %   b1 - Vector 1x4 que representa la primera bounding box [x1 y1 x2 y2]
    %   b2 - Vector 1x4 que representa la segunda bounding box [x1 y1 x2 y2]
    %
    % Output:
    %   iou - Valor escalar entre 0 y 1 que representa la IoU.
    %         IoU = 0 si no hay solapamiento.
    %         IoU = 1 si las cajas son idénticas.

    x1 = max(b1(1), b2(1));
    y1 = max(b1(2), b2(2));
    x2 = min(b1(3), b2(3));
    y2 = min(b1(4), b2(4));
    inter = max(0, x2-x1) * max(0, y2-y1);
    area1 = (b1(3)-b1(1))*(b1(4)-b1(2));
    area2 = (b2(3)-b2(1))*(b2(4)-b2(2));
    union = area1 + area2 - inter;
    if union>0
        iou = inter/union;
    else
        iou = 0;
    end
   
end
```

# Ejercicio 4 - Non-Maximum Suppression

En este ejercicio, tu objetivo es implementar **Non-Maximum Suppression (NMS)** para eliminar detecciones solapadas redundantes de la misma clase.


**Cómo funciona NMS**


El algoritmo básico de NMS consta de estos pasos:

1.   **Filtrar por puntuación de confianza:** Eliminar todas las cajas con confianza (objectness × probabilidad de clase) por debajo de un umbral (por ejemplo, `0.25`).
2. **Ordenar cajas por puntuación:** Ordenar las cajas restantes en orden descendente según sus puntuaciones de confianza.
3. **Suprimir cajas solapadas:**

-  Tomar la caja con mayor confianza, llamarla `B1`. 
-  Calcular la **IoU (Intersection over Union)** de `B1` con todas las demás cajas. 
-  Si `IoU > IoUThreshold` (por ejemplo, `0.5`), descartar esas cajas, ya que probablemente representan el mismo objeto. 
-  Repetir con la siguiente caja restante.

```matlab
    boxes = vertcat(detections.boxes);  % Nx4
    conf  = vertcat(detections.conf);   % Nx1
    cls   = vertcat(detections.cls);    % Nx1
    
    N = size(boxes, 1);         % Número total de detecciones

    % Ordenar detecciones por confianza descendente
    [~, order] = sort(conf, 'descend');

    keep = false(N,1);          % Máscara booleana para registrar qué cajas se conservan
    
    % Iterar sobre las detecciones en orden
    for k = 1:N
        idx = order(k);         % Índice de la detección actual
        keepThis = true;        % Indicador de si se conserva la caja actual

        % Comparar con cajas previamente conservadas
        for j = find(keep)'     % Índices de cajas ya conservadas
            if cls(idx) == cls(j)   % Comparar solo cajas de la misma clase
                iou = calculateIoU(xywh2xyxy(boxes(idx,:)), xywh2xyxy(boxes(j,:)));
                if iou > iouThreshold
                    keepThis = false;
                    break;
                end
            end
        end

        if keepThis
            keep(idx) = true;
        end
    end

    % Conservar solo las detecciones seleccionadas
    filteredDetections.boxes = boxes(keep,:);
    filteredDetections.conf  = conf(keep);
    filteredDetections.cls   = cls(keep);

    removed = sum(~keep);
    if removed > 0
        fprintf('Filtered: removed %d overlapping detections\n', removed);
    end
end
```
